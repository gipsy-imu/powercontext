# 给 Qoder 的开发任务

在当前工作区、当前分支 `codex/qoder-study-search` 实现「研迹」，一个面向学生和复现实验的科研笔记检索工具。全部项目资产放在 `qoder/`。这是 OceanBase 2026 赛题，请在 Qoder 中完成需求拆解、开发、调试和验证，并沿用这段对话记录实际过程。赛题原文在 [官方语雀](https://oceanbase.yuque.com/org-wiki-obtech-vh7w9r/hc3pio/uygu3273xzlrcmrm)。

## 主要流程

1. 导入一批 UTF-8 Markdown 或 TXT 笔记，保留笔记标题、段落标题、来源和原文。支持内置示例一键导入。
2. 将段落写到真实的 seekdb，使用全文索引执行搜索，支持按报告或标签筛选。结果显示标题、匹配片段和来源。点开来源可以查看原段落。
3. 做一个简洁的中文界面，打开即可运行示例。数据库服务不可用时明确显示连接或初始化错误。

## 环境和交付

- 采用 Python 和常见依赖。使用可在评测环境复现的 seekdb 部署方式，优先使用官方 Docker 镜像和 MySQL 协议，同时允许配置已有 seekdb 实例。为样例固定可复现的依赖版本，启动步骤写入 `qoder/README.md`。环境变量示例使用占位值。
- 用自行撰写的示例笔记覆盖中英文搜索、同名段落、重复导入和无匹配结果。示例内容可围绕时间序列分类，例如「采样窗口」「长度对齐」「类别不平衡」以及 `macro F1`。为至少三条查询写出预期命中和来源。
- 提供从干净环境启动、初始化、导入示例、运行验证的命令。实际跑通数据库后，记录命令和观察结果。README 说明索引和查询在哪里执行。
- 产出实际运行截图和一份项目展示页文案。展示页要能说明问题、主要功能、seekdb 的作用和复现方式，附运行截图、项目仓库及体验入口（如可用）。项目开发完后，通过 Qoder Sites 创建站点并由我确认发布和公开访问。
- 保存关键开发环节的真实 Qoder 对话截图或录屏。待我提供站点网址和 Qoder UID 后，再把它们和材料路径写入 `qoder/README.md`。
