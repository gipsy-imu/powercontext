# 可穿戴动作识别复现报告 B

## 采样窗口

复现论文实验时，采样窗口取 128 个时间步、步长 64 的滑动窗口，与原作者配置保持一致。
窗口参数是复现结果差异的主要来源之一：我们只改了窗口长度，其他配置不变，
同一份随机森林代码的准确率就从 0.812 掉到了 0.776。

## 长度对齐

部分被试的传感器中途掉线，导致序列长短不一。我们没有重采样，而是统一做零填充到最大长度
（zero-padding alignment），并在注意力层用掩码屏蔽填充位。
另一种等价做法是把窗口切分完全交给数据加载器处理。

## 类别不平衡

"其他"类别在测试集里只占 1.2%，任何轻微抖动都会让 macro F1 明显下滑，
因此所有对比实验都同时记录 accuracy 与 macro F1 两个指标。
最终采用阈值校准：对少数类放宽判定阈值，macro F1 从 0.74 回升到 0.79。

## 结果对比

与报告 A 不同，本次最佳模型是轻量级 LSTM（约 27 万参数）。
在长度对齐 + 阈值校准两个技巧叠加后，macro F1 达到 0.838，
但推理延迟比随机森林高约六倍，嵌入式设备上需要注意。
